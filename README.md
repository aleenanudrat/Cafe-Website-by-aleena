My Cafe Website

My Cafe is a responsive and interactive café website where visitors can explore coffee, pastries, menu prices, and place orders online.

Developed using HTML, CSS, and JavaScript.

Features
Home and About Us sections.
Read More functionality.
Menu with category filters (All, Drinks, Pastries).
Interactive item selection and automatic bill calculation.
Contact and order form.
Dine In and Takeaway options.
Special offers subscription.
Special request character counter (100 characters).
Light/Dark mode toggle.
Café opening status.
Responsive design for all devices.
Technologies Used
HTML5
CSS3
JavaScript
How to Use
Open the live website.
Explore the Home, Menu, About, and Contact sections.
Browse and select menu items to calculate your bill.
Switch between Light and Dark modes.
Fill out and submit the order form.

To run locally, download the project and open index.html in your browser.
